# v2.1.0 验证记录

- 25 项自动化测试通过，覆盖原文及对象保留、自定义规范快照和参数校验、批量删除、原文件保护、被占用副本清理、草稿备份恢复、模板转义、照片验证及字体密钥字节序
- 原生 Qt 界面验证通过，覆盖搜索后全选并批量删除、自定义规范编辑及应用、任务组编辑、切换模板恢复草稿、原生保存流程及生成后加入记录
- 打包 EXE 原生流程通过，示例文档 65 处可自动问题复检归零，生成真实 DOCX、TXT 检查报告和 ZIP，未载入 HTTP 服务或 QtWebEngine
- 七类本机模板生成 11 份测试 DOCX，覆盖封皮、年度及月份计划、年度及月份总结、文化导航申报表；照片覆盖单列、两列、三列及不同插入位置
- 使用本机 Microsoft Word 将 11 份 DOCX 转换为 PDF，检查各页图像中的封皮、标识、正文、表格、落款、照片与页码，未发现截断或对象丢失
- 公开源码包排除本机模板、字体、规范原件、标识图片、个人草稿、测试档案和二进制发行包

运行方式见 README。`scripts/qa_generator.py` 需要自行配置模板资源；`scripts/qa_generated_office.py` 需要本机 Word；`scripts/qa_native_features.py` 使用合成测试数据操作应用自身的 Qt 控件

当前环境没有安装 WPS，尚未做 WPS 实机验证。最终分页仍受接收方字体和软件版本影响
