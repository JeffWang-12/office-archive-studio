# v2.2.1 修复清单

本版汇总 A、B、C 三批修改，沿用 v2.2.0 的 Python 原生窗口、完整生成表单、自定义规范和本机数据目录

| 编号 | 原问题或保留要求 | 本版行为 |
| --- | --- | --- |
| A1 | history.json 顶层不是列表或混入非对象元素时可能异常或部分载入 | 先验证完整结构，无效则放弃载入并保留原文件，同时保留未确认删除的暂存副本 |
| A2 | 损坏、缺表、解码失败或无法读取的字体可能中断环境检测 | font_metadata 捕获指定异常，统一返回空名称和未知嵌入标志 |
| A3 | 文档类型失效后生成和错误定位可能抛出 KeyError | 生成时提示刷新文档类型，错误定位直接返回 |
| A4 | 导出直接写目标，写入中断可能损坏已有文件 | 单文件和 ZIP 导出先写同目录 .tmp，成功替换目标，失败清理临时文件；路径校验保持原样 |
| A5 | Office 转换脚本缺失或为空时仍尝试启动转换 | 调用 subprocess 前检查脚本并给出重新安装提示；本版保留 Bypass，并留有评估 RemoteSigned 的 TODO |
| A6 | 记录目录创建、日志初始化或 Store 创建失败时缺少启动提示 | 捕获 OSError，提示使用 --data-dir 并返回 1，处理位于加锁之前 |
| B1 | 数字分隔的成文日期未被识别为日期 | 增加 YYYY-M-D、YYYY/M/D、YYYY.M.D，与中文日期并列，署名联动识别且优先级不变 |
| B2 | 首节没有 default 页脚时无法按指定兼容策略检查后续引用 | 以最近后续 default 回填起始引用，后续逐节继承；所有节都解析并检查，任一节失效或不合规均失败 |
| B3 | 无字体文件时单行判断使用固定字符数，不能适应实际可用宽度 | 使用 int(available_pt / 16) 作为全角上限，并保留半角折算；有字体时精确测量路径不变 |
| B4 | 底层计划生成超过 12 个任务时，中文编号元组会越界 | 1–12 保留中文编号，超过 12 回退数字字符串，调用改为一基序号；表单原有限额未放宽 |
| B5 | 历史记录临时文件替换前缺少显式刷盘 | write、flush、fsync、关闭文件后再 replace，保留 UTF-8 无 BOM |
| B6 | 长文件名截断可能丢失扩展名，或在非法字符过滤前占用长度 | 先取 basename 并过滤，再拆 stem/suffix，仅截断 stem 后拼回扩展名 |
| B7 | 已删除或无效记录进入 analyze、fix、report 时可能抛出 KeyError | 三个入口先调用 folder，统一使用失效记录提示；两个 export 函数保留 A4 实现 |
| C1 | 后台任务期间，已展开菜单或直接调用仍可能操作模板和草稿 | 七个指定动作开头检查 host.busy，在忙碌时立即返回，不弹窗、不保存、不清理 |
| C2 | 忙碌期间忽略自动保存切换会使复选框与实际状态不一致 | 阻断信号、反向恢复勾选、恢复信号后返回，避免递归和设置写入 |
| C3 | 打开模板资源目录是只读操作 | 保留原入口且不添加 busy guard，任务期间仍可调用 |

B2 的首节向后回填为本次约定的兼容行为；严格 OOXML 从前节继承，首节缺省为空页脚，见 [微软 FooterReference 说明](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.footerreference?view=openxml-3.0.1)

## 手工验证命令

在已安装 requirements.txt 依赖的源码目录中运行现有 desktop.main smoke 入口，不改 smoke 断言；测试使用独立数据目录

```powershell
python -m unittest discover -s tests -v
python -c "from app.desktop import main; raise SystemExit(main())" --data-dir .\qa-v221\records --smoke-test .\qa-v221\result.json
Get-Content -Encoding utf8 .\qa-v221\result.json
```

在桌面发布目录中运行成品 smoke，PowerShell 使用 Start-Process 等待窗口程序退出

```powershell
$qa = Join-Path $env:TEMP ('ArchiveStudio-v221-' + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $qa | Out-Null
$args221 = '--data-dir "' + (Join-Path $qa 'records') + '" --smoke-test "' + (Join-Path $qa 'result.json') + '"'
$process221 = Start-Process -FilePath '.\归档.exe' -ArgumentList $args221 -WindowStyle Hidden -PassThru -Wait
$process221.ExitCode
Get-Content -Encoding utf8 (Join-Path $qa 'result.json')
```

通过条件为进程退出码 0，JSON 中 ok=true、version=2.2.1、before=65、after=0，checks 共 11 项；目录版可将 FilePath 改为 .\归档\归档.exe

公开仓库和源码包不包含本机字体、模板、原始规范、填写草稿和包含这些资源的二进制发行包

本版打包内 office.ps1 已与源码校验一致，Word 实际转换两份 smoke 导出文档成功，PDF 渲染检查正常；当前环境尚未完成 WPS 实机验证
