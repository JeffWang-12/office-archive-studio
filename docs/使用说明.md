# 归档 原生桌面版使用说明

这是 Python + PySide6 编写的 Windows 桌面软件。全部界面使用 Qt Widgets 原生控件；不启动浏览器、本地网页服务、WebView 或网页引擎。

## 启动

公开发行页只提供 Python 源码，不提供包含用户字体和规范原件的安装包。按 README 安装依赖后运行 `python main.py`，关闭窗口即退出程序。DOCX 修正无需联网或安装 Office。

Python 源码版可运行 `python main.py`；首次运行前按 README 安装依赖。打包发布使用 `scripts/build.ps1`。

## 使用步骤

1. 在“格式工作台”选择内置规范或自定义规范，点击“添加文件”，或直接拖入 DOCX / DOC / WPS。可先点击“体验示例”。
2. 在清单中选中文件查看格式问题和人工核对事项。点击“段落识别”，逐段确认主标题、标题层级、正文和落款；保存后重新检查。
3. 点击“一键修正格式”。内容完整性校验通过后，使用原生保存对话框另存规范 DOCX，也可导出检查报告。多份文件可批量修正、打包导出。
4. 到“兼容与字体”检测 Windows 字体。开源版不随附字体，请使用你已有权限使用的本机字体；安装后重启 Word/WPS 并重新检测。“应用内预览”不代表系统已安装字体。
5. 如需打印，点击“生成 PDF”，选择本机 Word 或 WPS 排版组件及保存位置。也可在原软件中手动另存为 PDF。

格式处理在后台线程执行，窗口保持响应。处理过程中请等待完成后关闭。原始文件不会被覆盖，导出到原始路径的操作会被拒绝。

## 本机记录

发行版保存在 Windows 用户本地应用数据目录的 ArchiveStudio/records 中。源码版默认保存在项目 .local_data，也可通过 --data-dir 指定。记录可在“处理记录”中查找、继续处理或删除。勾选文件名前的复选框，或使用 Ctrl / Shift 多选；“全选当前结果”仅选择搜索后可见记录，点击“删除所选记录”统一清理。原始文件与已导出文件保留。

## 自定义文本格式规范

工作台点击“管理规范”，或进入“档案规范 → 我的格式规范”。新建规范后，可设置各类段落的中文字体、字号、固定行距、首行字符缩进和对齐方式；“版面”中设置 A4、A5 或 Letter 纸张及六项边距。字体名称应与 Windows 中的字体名称一致。

保存后在工作台下拉框选用再导入文件；已导入文件在“检查设置”中切换规范并重新检查、修正。修改或删除规范不会改变旧记录的规范快照。支持 JSON 导入和导出，便于同部门共享设置。段前段后统一归零，页码沿用团内规范；图片和表格内部格式保留。

## 档案生成

“档案生成”将七类模板整合在同一个原生窗口中：年度及月份封皮、工作计划、工作总结、文化导航申报表。按“基本信息、主要内容、活动与照片、落款”填写。每行一条的内容自动编号，工作任务可动态添加、移除，目录和活动明细使用表格编辑。

总结选择 2–3 张不同的照片，可设置照片位置、单列 / 两列 / 三列和是否单独成页。程序检查照片尺寸、重复及损坏情况，并保持比例、纠正照片方向。照片短边至少 300 像素，每张不超过 25 MB。

“生成并另存 DOCX”先验证填写内容，再选择保存位置。生成文件也会加入工作台，可进一步检查并通过本机 Word / WPS 生成 PDF。生成器保留模板版式，不强制再次套用纠正器规则；封皮和图表需人工核对最终分页。

默认只在本机保存各模板的草稿，切换模板和退出前会保存。可关闭自动保存，或清空当前草稿；关闭自动保存不会删除已有草稿。草稿文件损坏时尝试读取备份。新软件不会自动读取提供文件夹中的原有个人草稿。

本机完整版包含已整合的模板资源。开源版使用“导入资源”选择包含 templates 文件夹的目录，或通过“添加模板”导入含 `{{ 名称 }}` 占位符的 DOCX；程序自动识别填写字段。只复制模板、模板清单和字体，不执行资源目录中的 EXE 或 Python 文件。“恢复标准模板”会验证恢复资源并重置七份标准模板，自定义模板和草稿保留。

“嵌入可授权字体”默认关闭，开启后跳过字体标志禁止嵌入或仅允许位图嵌入的字体。没有字体文件时保留模板指定的字体名称。字体嵌入不能保证所有 Word / WPS 版本分页一致，接收方可能仍需安装所需字体。

## 支持范围

- DOCX：单份不超过25MB，解压后的文档包不超过120MB。
- DOC/WPS旧版文字文件：需要本机可用的Word/WPS自动化组件，转换后核对图片、表格及分页。
- PDF导出：需要可用的Office自动化组件，环境检测不等于实际转换成功。
- 原文、图片、表格、文本框、批注、书签及编号关系保留；表格内部格式保留。
- 复杂页脚提示人工处理；不直接修正含宏、加密、数字签名、限制编辑或修订未处理的文档。
- 不直接编辑PDF、Excel，不进行正式档案考核评分。

不同Word/WPS版本、字体替代和打印驱动仍可能造成分页差异。正式提交前核对规范字体、图片、附件、落款、印章和最终PDF效果。WPS尚未在当前环境实机验证。
