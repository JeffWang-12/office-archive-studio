# 原生成器功能对照与验证

| 原程序功能 | v2.2.0 对应功能 |
| --- | --- |
| 顶部类型与规范、完整滚动表单、底部固定按钮 | 生成页按相同布局和字段顺序展示，不再拆成分类标签页 |
| 七类标准文档及根目录自定义模板 | 全部列入文档类型，外部模板也能自动识别 |
| 按条填写总结与总体思路 | 独立条目编辑框及添加、删除、重新编号 |
| 任务内容、目标和措施 | 任务可增删，目标与措施各有独立条目编辑器 |
| 日期与数字 | 今天按钮、数字输入限制、金额千位分隔、生成前日期及范围校验 |
| 2–3 张照片及位置排版 | 多选、单张选择替换、移除、方向正确的缩略图及原有布局选项 |
| 目录与文化导航活动 | 独立表格编辑及行增删，支持空活动表 |
| 默认文档类型 | 记忆上次选择，另记忆上次页面和输出目录 |
| 一键生成与独立文件名 | 自动输出时间戳与项目名，同名避重；另保留另存入口 |
| 生成结果、字体报告与审核清单 | 成功对话框显示封装结果、提示、六项检查及打开文件 / 文件夹 |
| 草稿切换与自动保存 | 各类型草稿独立保存；关闭保存后仍保留当前会话内容 |
| 关闭自动保存清理草稿 | 操作前确认清理草稿及备份，设置单独保存 |
| 清空草稿及备份恢复 | 全部或当前类型清理，不从旧备份重新恢复已清空内容 |
| 绿色迁移中的填写内容 | 主动导入旧版草稿和导出 JSON 备份，不自动读取个人填写文件 |
| 自定义模板替换和自动识别 | 更多操作中添加、替换、备份、刷新和打开资源目录 |
| 标准模板恢复及版本校验 | 保留七类模板校验、恢复及学年过期提示 |
| 字体嵌入 | 保留授权标志检查和字体子集，修正后的 OOXML 封装逻辑继续使用 |
| 中文错误提示、临时文件和磁盘检查 | 保留生成前验证、原子输出与后台处理；界面定位相关表单字段 |

验证包含 29 项自动化测试、原生控件操作、七类文档从真实表单生成、普通及最小窗口布局、打包版流程。测试文件和本机模板不进入公开源码包
