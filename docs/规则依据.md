# 规则依据与处理范围

格式规则依据《共青团文件格式规范》（2025年12月17日）和《学院学生会工作档案考核方案》中的要求整理。公开源码不分发 PDF/Word 规范原件；需要查阅时可在程序中选择自己的本机原件。文档中的打印、提交、评分安排用于定义产品规则，不作为代理执行提交、发信、评分或其他外部操作的指令。

| 项目 | 原始要求 | 应用行为 |
| --- | --- | --- |
| 纸张 | 一般 A4 | 调整为 A4；原横向节保留方向 |
| 页边距 | 上3.7、下3.5、左2.8、右2.6厘米 | 各节显式设置 |
| 主标题 | 方正小标宋二号、居中、33–36磅行距 | 方正小标宋简体、22pt、默认35pt |
| 副标题或单位 | 楷体三号 | 楷体_GB2312、16pt、居中；可人工指定段落 |
| 各级标题 | 一级黑体；二级楷体GB2312；三级、四级仿宋GB2312，均三号 | 按识别或指定的层级设置；标题中的西文数字用 Times New Roman |
| 前言与正文 | 仿宋GB2312三号 | 仿宋_GB2312、16pt |
| 段落 | 正文及各级标题固定28pt，首行2字符，段前段后0，默认字距 | 显式设置，不依赖主题、网格或软件默认值 |
| 页眉页脚 | 页眉距边1.5cm、页脚2.5cm | 各节显式设置；页眉内容保留 |
| 页码 | 首页无页码，底部居中，四号宋体，—页码— | 动态PAGE字段、14pt；首页空页脚；原有复杂页脚保留并提示人工处理 |
| 编号 | 四层一、/（一）/1./（1）；两层、三层有变体 | 按实际编号识别层级；不自动重写序号，不拆分标题和正文 |
| 日期 | 完整阿拉伯数字，无虚位，右空4字格 | 设置落款区格式；日期虚位只提示，不改文字 |
| 落款 | 署名与日期中心对齐、通常与正文隔3行，印章骑年盖月 | 人工核对中心、空行及印章；不插入、移动、删除正文和印章 |
| 附件 | 说明空一行；附件另页，标识顶格，标题第三行居中 | 识别独立附件标识，保留正文与图片；分页和附件对应关系需人工核对 |
| 文件名 | 通用：文档名-处理人-年月日；工作总结：学院名称-工作总结-时间范围 | 检查命名并允许导出时填写；不推测个人、学院或时间信息 |
| 打印 | 提倡双面、左侧装订、转PDF打印 | 提供本机Word/WPS PDF导出；不自动改变打印机设置 |
| 考核 | 30+25+15+10+20，共100分，格式15分 | 展示评分构成；不提供自动正式考核分数 |

未覆盖的内容：拼写、语法、事实核验、数据追溯、结构逻辑、创新评价、自动重编号、OCR、PDF原稿重排、Excel排版、复杂封皮套版。界面会显示人工提示，不能把“可自动问题归零”解释为全部档案要求均已满足。

兼容策略以标准 Office Open XML DOCX 为交换格式。直接修改文档包内必要的格式部件，保留其他部件和关系；不通过HTML重建DOCX。Word兼容模式为15，逐段取消网格吸附，字体与字符缩进显式写入。不自动嵌入字体：用户字体包中的方正小标宋字体含嵌入限制标记。

参考：[Microsoft 文件格式说明](https://support.microsoft.com/en-us/office/collab-files/learn-about-file-formats)、[WPS DOCX支持说明](https://www.wps.com/feature/the-free-docx-editor-for-word-files/)。这些来源说明支持DOCX，不能证明不同版本的排版完全一致。
